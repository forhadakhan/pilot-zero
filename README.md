# 🚀 Pilot Zero

Welcome to **Pilot Zero** — a sample repository crafted for a hands-on tutorial introducing GitHub to beginners. This project is designed to help new developers get comfortable with basic GitHub workflows such as cloning, branching, committing, and pushing.

## 📚 Purpose

This repository serves as a sandbox for experimentation and learning. It was created as part of an **in-person workshop conducted for a small group**, aimed at:

- Teaching the fundamentals of version control
- Demonstrating collaborative workflows
- Exploring GitHub features like pull requests, issues, and project boards

## 👩‍💻 Who It's For

Whether you're a student, a hobbyist coder, or someone curious about open source, this tutorial is designed to be beginner-friendly and easy to follow.

## 🔧 What's Inside

You’ll find:

- Sample code files and folders
- A simple branch structure to explore
- Exercises to help you practice common Git tasks

## 🌐 Resources

Feel free to fork the repository, explore the history, and contribute as you learn!
